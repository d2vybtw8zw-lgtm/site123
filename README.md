# Atelier — пять сайтов на Three.js

В корне лежат готовые страницы со встроенными CSS и JavaScript:

- `index.html` — общий каталог
- `bicycle.html` — конфигуратор велосипеда и заказы
- `apartment.html` — прогулка по квартире
- `voxel.html` — мир из блоков
- `racing.html` — гонка и рейтинг
- `arena.html` — сбор звёзд

## Статический режим

Откройте `index.html` или загрузите шесть HTML-файлов на статический хостинг. Нужен интернет для загрузки Three.js 0.160.0 с jsDelivr. Устанавливать что-либо посетителю не нужно. CSS и код каждой сцены находятся внутри соответствующего HTML.

В статическом режиме заказы, блоки и рекорды сохраняются в localStorage браузера; вкладки одного источника синхронизируются через BroadcastChannel. Этот режим **не объединяет разные устройства**. Статус отображается в шапке. Локальные данные автоматически на сервер не переносятся.

## Общий сервер для разных устройств

На компьютере или хостинге с Node.js 18+:

```sh
npm start
```

Откройте http://localhost:3000. Для телефона в той же Wi-Fi сети используйте IP компьютера и порт 3000. Для публичной ссылки разместите всю папку на Node.js-хостинге с постоянным диском, командой `npm start` и переменной `PORT` от хостинга. Без серверного размещения публичной ссылки и общего состояния между устройствами нет.

Сервер не требует npm-зависимостей. SSE рассылает изменения всем посетителям, POST принимает действия. Заказы, блоки и рекорды записываются атомарно в `state.json`; для сохранения после перезапуска хостинга нужен постоянный диск. Используйте один процесс сервера. Игроки исчезают через 12 секунд без обновлений. Звезда начисляется на сервере одному игроку с проверкой расстояния. Телефоны заказчиков хранятся в `state.json` и не выдаются в публичном API.

Это демонстрационный проект: нет авторизации, защиты от поддельных игровых результатов, ограничения частоты запросов и административного интерфейса. Имена и комплектации заказов доступны посетителям. Для реального магазина нужны закрытый доступ к заказам и политика обработки персональных данных.

## Управление

- Велосипед: перетаскивание; на телефоне откройте «Настроить».
- Квартира: WASD/стрелки, перетаскивание камеры; телефон — джойстик и свайп.
- Блоки: WASD, пробел, перетаскивание; короткий левый клик ломает, правый ставит; 1–6 выбирают материал. На телефоне отдельные кнопки.
- Гонка: WASD/стрелки, телефон — кнопки; Enter отправляет форму имени.
- Арена: WASD/стрелки или экранные кнопки. Звука нет.

Pointer Lock не используется. Модели созданы процедурно. `tools/build.py` генерирует все HTML-файлы; после изменения генератора выполните `python3 tools/build.py`.
